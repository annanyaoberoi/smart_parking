Smart Parking Allocation System 🚗

📌 Project Description
The Smart Parking Allocation System is a C-based application that uses graph algorithms
to optimize parking slot allocation in a smart city environment.  
It uses Dijkstra’s Algorithm to calculate the shortest path between locations and helps
users identify the nearest available parking area efficiently.

This project demonstrates the real-world application of Data Structures and Algorithms
in traffic management and smart city infrastructure.

🎯 Objectives
- Optimize parking slot allocation
- Reduce traffic congestion
- Minimize travel time
- Improve urban traffic management
- Apply graph algorithms in real-world scenarios

🧠 Algorithm & Concepts Used
- Dijkstra’s Algorithm  
- Graph Theory  
- Greedy Algorithm Approach  
- Adjacency Matrix Representation  
- Shortest Path Optimization  

🛠 Technologies Used
- C Programming Language  
- Data Structures  
- Algorithms  
- Graph Theory
